# Brand assets

The mark is a drive stack with the top drive lifted off. It is black and white only.

| File | Use |
| --- | --- |
| `icon-mark.svg`, `icon-mark-1024.png` | macOS app icon foreground. White on transparent; import into Icon Composer as the single layer and let macOS draw the tile for light, dark, clear and tinted. |
| `menu-bar-template.svg`, `menubarTemplate.png`, `menubarTemplate@2x.png` | Menu bar glyph. Black on transparent; mark it as a template image so macOS tints it. |
| `favicon.svg` | Web favicon. Black in light mode, white in dark mode. |

Geometry lives on a 100 unit grid. The glyph versions use heavier strokes so they hold up at 16 px.
